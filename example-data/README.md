# EXAMPLE DATA

Everything in this folder is **EXAMPLE DATA**. It is canned sample output for the Gitleaks demo. Nothing here is a real credential, private prompt, or internal config.

- `expected-output.json` — the canonical canned run of `scripts/run-demo.sh` (seeded finding detected).
- `scenarios/` — the three fixed visitor choices shown on the live demo page.
- `gitleaks-allowlist-demo.toml` — example scanner config used only for the allowlisted-path scenario.
